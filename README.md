### Focus

Software Engineer based in Hanoi, Vietnam. Specializing in full-stack web platforms, API gateways, and cross-platform mobile development:

- **Web Systems:** Next.js 15, React 19, strict Content Security Policy, and PostgreSQL database transactions.
- **AI Tooling & Gateways:** Reverse-proxy gateways with session pooling and rate-limit handling, RAG pipelines, and agent CLI integrations.
- **Mobile Development:** Cross-platform mobile applications with Flutter, Dart, and local SQLite / Supabase storage.
- **Verification:** Automated testing with Vitest, Playwright E2E browser tests, and Docker environments.
